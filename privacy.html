Privacy Policy

Effective date: May 17, 2026

1. Overview

SoS Media Engine is a personal, single-operator content automation tool. It does not collect, process, or store any personal data from third parties.

2. Data We Collect

We do not collect any personal data from users. The application is used exclusively by its creator/operator and interacts with social media APIs only on behalf of the operator's own accounts.

3. Third-Party API Usage

This application connects to the following APIs on behalf of the operator only:

  • TikTok Content Posting API — to post videos to the operator's TikTok account
  • YouTube Data API v3 — to upload videos to the operator's YouTube channel
  • Instagram Graph API — to publish Reels to the operator's Instagram account

No data from these platforms is shared with any third party. OAuth tokens are stored locally on the operator's device only.

4. Data Storage

All credentials and tokens are stored locally on the operator's personal Mac computer. No data is transmitted to any external server beyond the platform APIs listed above.

5. Data Sharing

We do not sell, trade, or share any data with third parties.
